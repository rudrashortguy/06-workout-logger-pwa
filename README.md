# FitFlow - Gym Tracker & Rest Intervals

Track sets, reps, and weights offline during workouts with built-in rest timers and exercise history logs.

## Features
- Exercise library & custom routines
- Rest timer with audio/vibration
- Previous set weight & rep recall
- Workout history analytics

## Tech Stack
- **Vite** & **React 18** with TypeScript
- **Tailwind CSS** for responsive mobile-first styling
- **Workbox / Vite PWA Plugin** for offline caching & service worker lifecycle

## Development
```bash
npm install
npm run dev
```
